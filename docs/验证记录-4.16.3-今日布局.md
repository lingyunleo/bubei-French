# 4.16.3 今日页布局验证记录

本次仅压缩手机端“今日”页的留白，继续归入 4.16.3。以已包含性能优化、扉页启动和标熟功能的提交 `2d86edbf4ee3cc56a03333216b1e83c4f10043fd` 为基线，没有修改学习逻辑、数据结构或存储键。

## 改动范围

- `src/app.js`：给今日页主区域增加 `today-main` 样式标记。
- `src/product-polish.css`：在手机宽度下减少页头、标题、续学卡片及学习卡片的间距；较矮屏幕进一步压缩留白。保留文字、计数动效和至少 48px 高的主要操作按钮。
- 其他页面及桌面布局不使用这些新增规则。长词表名称允许换行，内容不裁切、不截断。
- 从源码重新构建根目录单 HTML，保留单文件启动方式。

## 实际验证（2026-10-06）

使用独立 Chromium 154.0.8037.93 与 WebKit 26.5 上下文直接打开生成的 HTML，以合成词条和测试会话检查，不读取真实浏览器资料。

- 76 个布局场景：三种界面语言、三种主题、浅深色、完整/简约动效；390×712、390×844、375×667、430×932、320×568 和 1440×900；含有/没有续学卡片、长词表名称、放大文字及自由学习。无横向溢出，主要操作按钮高度不少于 48px。
- 2 个续学检查：在拼写中输入文字，返回今日，再通过“继续学习”进入，输入保持一致。
- 原有 `product-polish-review.cjs` 28 项、`appearance-morph-review.cjs` 16 项全部通过，确认标题、计数、例句卡片与弹窗动效，以及主题切换、拼写输入和页面布局。
- 上述本轮检查共 122 项/场景，页面脚本错误为 0。未将上一轮检查数量累加为本轮结果。

同口径的 390×712 中文 VERDURE 浅色、有未完成小组场景，学习卡片底部从约 697px 提前到约 580px；底部导航从 641px 开始。两个学习按钮因此都完整位于导航上方。375×667 中文场景也能完整展示这些卡片。

法文等较长文案在 375×667、320×568 等较小尺寸下仍可能需要少量滚动；放大文字或很长的范围名称也保留自然滚动，没有通过隐藏信息强制塞入首屏。
