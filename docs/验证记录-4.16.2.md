## 本次修复验证

- 生成 2001 条不同的合法 WAV，使用 Chromium 原生 IndexedDB 保存、刷新、导出并在全新上下文恢复；录音字节、标识和来源/许可字段一致。再次恢复不重复写入，标识冲突不会覆盖原文件。
- 非法录音标识、格式、编码、内容、许可链接及超过单条 15 MiB / 总量 150 MiB 的输入被拒绝；失败批次不写入。
- 拼写、听写和撤销快照缺少必需计数、出现异常数值时被拒绝；合法备份恢复后仍可答题、保存和重载。缺省技能记录、可选订正字段及撤销前未练习的记录仍兼容。拒绝损坏保存或快照恢复时保留原数据与版本。
- Chromium / WebKit 验证原生 WAV 播放、弹窗内停止和关闭、弹窗外停止、例句自然结束后在循环间隔中启动单词，确认旧循环不再重启。
- 停止按钮只有一个，随弹窗迁移；390px 三主题下在屏幕内且不遮挡底部操作。桌面和窄屏关键截图已人工检查。
- Chromium 实际导出含录音的便携 HTML 并重新打开，按钮、播放和停止仍正常。测试发现过按钮排到脚本之后导致便携启动失败的问题，已改为放在脚本之前并重测通过。
- 拼写输入中 Esc 保存草稿并返回；刷新续接仍保留草稿、当前题目、学习事件、调度与技能状态。弹窗内 Esc 只关闭弹窗；输入法组字不返回；Enter 判分、输入字母以及 P/S 快捷键保持原行为。

## 范围和限制

浏览器为 Chromium 154.0.8037.93 和 Playwright WebKit 26.5。390px 是触摸尺寸模拟，**实体手机软键盘、实际 Safari/iOS、Firefox、系统声音听感未测试**。

录音使用真实原生媒体播放及结束事件，但 WAV 是静音测试资料。合成朗读使用受控替身，只验证调度，不代表设备音源或听感验证。

本机 Playwright WebKit 的 file:// 上下文在原生 IndexedDB 写入 Blob/File 时报告 `UnknownError: Error preparing Blob/File data to be stored in object store`，独立探针中普通文本可保存。该环境的音频交互检查改用拦截的测试 HTTPS 响应提供同样的 WAV，不替换 IndexedDB、AudioKit 或原生 Audio。**WebKit 本地录音保存和便携内嵌录音未通过验证**；这些路径已在 Chromium 验证。WebKit 便携检查覆盖启动、唯一停止按钮及测试 URL 录音。

Chromium 通过 Tab 到达停止按钮后用 Enter / Space 停止；本机 WebKit 的 Tab 默认设置跳过按钮，因此 WebKit 检查先聚焦按钮再发送真实 Enter / Space。Chromium 输入法使用浏览器协议组合输入；WebKit 用显式合成事件验证组字守卫，不能替代实体输入法测试。
