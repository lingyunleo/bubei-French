# 4.16.3 标熟功能

本次在已发布的 4.16.3 性能优化与扉页实现上添加标熟，版本号仍为 4.16.3。原发布附件、源码和作者修改的说明已在维护者本地归档。

## 使用方式

学习页底部左侧为“撤销”，中间为快捷键提示，右侧为“标熟”。手机上隐藏快捷键提示，保留两侧操作。词条详情也可标熟或取消标熟；词库的“已标熟”筛选可集中查看。

标熟后，该词计入当前范围的掌握数量，退出新词、复习、拼写、听写和错词练习。本组最后一个词标熟后正常进入总结。取消标熟恢复原有学习状态和复习时间，过期的复习会重新成为到期任务。重置词表会同时取消该词表的标熟状态。

## 数据与判分

- `card.manualMastered` 与 `manualMasteredAt` 独立记录标熟；不改写原先的 acquired、FSRS、复习时间、技能计数或学习事件。
- 进度和总结区分标熟与真实作答。今日、最近一周以及每日目标仍只统计实际学习事件。
- 会话的 `masteredIds` 记录本组暂时免练的词，`masteryPauses` 保留原题目、输入、提示、反馈、订正和重试状态。取消后回到同一轮时，跟写订正不能成为独立通过；真正进入后续轮次才重新独立作答。
- 原存储键、v4 完整备份格式、语言、主题和启动方式均保留。标熟随 JSON 备份、便携 HTML 和回收站恢复；既有未标熟的备份仍可使用。
- 标熟前保留恢复快照；保存失败不显示操作成功，也不切走原题。防止重复点击和保存过程中同时提交答案；预览入口明确仅保留本次会话。

## 实现位置

- `src/engine.js`：标熟、取消、撤销、队列排除、统计和暂停恢复。
- `src/data.js`：标熟相关字段及撤销、回收站记录的校验。
- `src/app.js`、`src/study-controls.css`：按钮、筛选、状态说明、三种语言和窄屏布局。
- `tests/mastery-engine-review.cjs`、`tests/mastery-browser-review.cjs`：合成词条验证，不使用真实学习资料。

仅移植标熟功能。未引入私人词书、教材、笔记、录音、自动阴阳性或其他个人版功能。

## 构建与验证

使用现有 `npm run build` 生成根目录的 `不背法语-4.16.3.html`；直接用浏览器打开即可使用。新增检查分别接入 `npm test`、`npm run test:browser`。实际执行结果见同目录的标熟验证记录。
