## 修复范围

正式单文件与开发预览均覆盖。三维场景、手写、主题样式、音频模块、学习引擎、数据模块和入门词条与 4.16.2 一致；没有降低动画质量或改变词库上限、存储键、v4 备份格式。

## 性能对照

在 Apple M1 / 8 GB、macOS、本机无头 Chromium 154.0.8037.93 上，按先后交替的顺序分别测试正式 4.16.2 和 4.16.3，各场景各运行 3 次，共 18 组。离线打开单 HTML，窗口为 1440×1000，保持沉浸动效与 WebGL 场景，未开启 CPU 节流。两版使用完全相同的虚构数据；没有同时运行其他浏览器检查。

以下为 3 次中位数。空白场景测量首次打开；带数据场景测量保存虚构词库后刷新。就绪指引导、演示控件出现且场景加载提示消失后的两个动画帧，并非浏览器首次绘制。

| 场景 | 4.16.2 引导就绪 | 4.16.3 引导就绪 |
| --- | ---: | ---: |
| 全新空白 | 996.4 ms | 870.3 ms |
| 50 词、250 条练习记录 | 1249.5 ms | 953.6 ms |
| 5000 词、25000 条练习记录 | 12483.5 ms | 991.2 ms |

5000 词为正式版允许的总量上限。大库启动的完整状态复制从 190 次、累计 11421.3 ms 降至 0 次；候选版只读取 2 次设置副本，耗时不超过 0.3 ms。

以相同 4 秒进度在开场与翻书镜头之间往返滚动，大库动画帧回调间隔中位数从 233.3 ms 降至 16.7 ms，95 分位从 283.3 ms 降至 16.7 ms；候选版滚动过程中完整状态复制为 0 次。这是 `requestAnimationFrame` 回调间隔，不等于实际显示器呈现帧率。

上述数据限于该本机环境，不代表 Safari、实体手机或所有真实词库。性能脚本只计时原有接口，不替换返回数据或删去动画；计时本身有少量双方共有的开销。不将绝对毫秒数设为持续集成门槛。

手动复测（先安装开发依赖及浏览器、构建当前版本，并准备原始 4.16.2 HTML）：

```sh

```

输出位于 `test-results/`，包含环境、各次样本、数据与文件校验值。全部样本词条和练习记录由脚本生成；脚本拒绝内嵌个人学习资料的便携 HTML。

## 范围和限制

浏览器为 Chromium 154.0.8037.93 和 Playwright WebKit 26.5。390px 检查是触摸尺寸模拟；**实际 Safari/iOS、实体手机软键盘、Firefox 和系统音源听感未测试**。

合成朗读使用受控替身验证语速、声音选择及播放调度，不代表设备音源或听感验证。录音回归使用原生播放与结束事件，但 WAV 为自编静音资料。

本机 Playwright WebKit 的 file:// 原生 IndexedDB 写入 Blob/File 仍报告 `UnknownError: Error preparing Blob/File data to be stored in object store`。该环境的音频交互检查用拦截的测试 HTTPS 响应提供 WAV，没有替换 IndexedDB 或原生 Audio。**WebKit 的本地录音保存和便携内嵌录音未通过验证**；相应路径已在 Chromium 验证。WebKit 检查覆盖便携入口启动、唯一停止按钮及测试 URL 录音。

公开仓库不附历史 HTML；未通过 `CARNET_PREVIOUS_RELEASE` 提供前一版时，3 项可选对照会明确跳过。本地已对照原始 4.16.2 完成；GitHub 自动检查结果以对应提交的 Actions 页面为准。
