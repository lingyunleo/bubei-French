## 同版本性能对照

Apple M1 / 8 GB、macOS、Chromium 154.0.8037.93、1440×900、无CPU节流，实际渲染器为 ANGLE Metal Apple M1。每场景每版5次，共50组；先完成B，再在相同浏览器、硬件、窗口、源码快照和虚构数据校验下完成C。大库为5000词、25000条合法练习记录。每次使用新上下文，浏览器进程及操作系统缓存可能预热。

目标就绪两版均按应用挂接、目标DOM/控件、实际场景就绪及两个RAF观察；返访不要求场景。它**不含扉页退出**。重看从调用show起单独计时；FCP使用浏览器paint timing，不替换为DOM出现时间。

## 发现并修复的问题

- 同页重复导航可能使启动交接失效；场景代际与路由交接已分离，当前有效目标完成时统一收敛。
- 旧场景回退结果可能干扰新场景，场景成功后仍可能在边界时刻触发6秒回退；已限定当前代际并在场景成功时停止预算。
- 只有旧 `motionMode:'simple'` 设置时，扉页曾未遵循原简约偏好；现与原设置映射一致。
- 例句页自行解除 inert 可能早于启动退出；现同时遵守章节及启动状态。
- 帮助按钮隐藏后焦点可能落到 body；补上安全交接。Chromium 中立即移除标题的临时 tabindex 会再次丢焦，现等真正 blur 后清理。
- 页面在准备中进入/返回缓存时，旧场景曾只被销毁而没有恢复；当前引导在 persisted pageshow 恢复局部场景，已移除的扉页不会重建。

初轮还修正了测试假设：已有控件回归需等待启动层退出；受保护存档现在先进入应用保护界面，需主动重看才能测试引导恢复。启动专项的重载用例需释放测试自己的二次延迟门控。这些中间失败保留于日志，未计入最终通过数。

发布时的首次 Linux CI 在手动场景回退用例失败：软件 WebGL 的同步准备可能跨过3秒提示与6秒自动回退，测试随后仍等待已被正常自动回退移除的按钮。本地注入7秒同步阻塞复现了该竞态。仅将手动按钮用例改为可控时钟，保留真实场景、按钮、静态回退和重复点击断言；自动回退用例仍使用真实前台时间。网站 HTML 未改变，最终远端结果以对应提交的 CI 为准。

第二次 Linux CI 的 Chromium 启动专项通过，WebKit 在合成页面缓存恢复时发生原生页面崩溃，日志包含 `No provider of eglDestroySync found` 及 Zink/Vulkan 驱动初始化失败。测试改为分任务派发 hide/show，确认旧挂载已销毁并等待清理帧后再恢复；回退夹具绑定当次挂载的结算函数，保留取消、重挂及真实场景断言。仅在 GitHub 无 GPU 的浏览器测试步骤指定 Mesa 软件渲染 `LIBGL_ALWAYS_SOFTWARE=true`、`GALLIUM_DRIVER=llvmpipe`，依据 [Mesa 环境变量说明](https://docs.mesa3d.org/envvars.html)；未关闭 WebGL，未改变产品或本机性能采样环境。启动专项提前执行以便尽早发现问题，全部原有专项仍执行。两次失败日志均保留，是否解决以最终 Linux CI 实跑结果为准。

## 环境与未测试范围

Chromium 154.0.8037.93、Playwright WebKit 26.5，macOS Apple M1 / 8 GB。手机为390px等触摸/尺寸模拟，不是实体设备。**实际 Safari/iOS、Android、Firefox、屏幕阅读器、真实软键盘、原生浏览器200%缩放、后台操作系统冻结及实际BFCache命中未测试。**

WebKit 的原生 offline:true 会使本环境连空白本地 HTML 都报内部错误；专项改为阻止所有 HTTP(S) 请求并记录任何意外请求，不宣称系统断网通过。便携源文件与正式文件均实测，源码未打包入口的导出拒绝是保留的限制。

声音参数及调度使用受控替身，未验证实际音源听感。此前已知的本机 WebKit file:// 原生 Blob/File 存储错误仍存在；音频交互以拦截的测试 HTTPS WAV 验证播放。WebKit 本地录音保存和便携内嵌录音仍未通过验证，Chromium 对应路径已覆盖。

录屏包含实际正式返回、受控延迟数据交接及隔离控制器快路径；隔离快路径不是完整网站的启动测速。首次绘制采用浏览器 paint timing 另行记录，DOM存在或RAF观察不等于像素已经显示。没有调用本机 Homebrew ffmpeg/ffprobe。
