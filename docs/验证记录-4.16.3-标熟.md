- 新词、到期复习、拼写、听写、指定小组和错词池均排除标熟词；最后一词标熟正常结束，取消后可恢复或重新进入小组。
- 标熟、取消与撤销不修改原 acquired、FSRS、dueAt、技能计数、真实学习事件及今日/周统计；真正答完和直接标熟不会重复计数。
- 已提示、已揭晓、答错后的反馈、订正输入与选区、已订正待下轮及 review relearn 均完整保留；同轮取消后跟写不计独立通过，后续新一轮允许独立通过。
- 真实双击只标熟原词；保存中返回首页不会执行过期标熟，保存中打开新面板不会被旧操作关闭；输入保留。
- 真实 JSON 下载与恢复、便携 HTML 离线重开、词条及词表回收站恢复、确认重置取消标熟均覆盖。

## 环境与限制

本机 macOS / Apple M1，Chromium 154.0.8037.93、Playwright WebKit 26.5。截图和触屏为浏览器模拟；实体 iOS / Android、真实软键盘、实际 Safari、Firefox、屏幕阅读器及真实音源听感未测试。

WebKit 在本机使用 `offline:true` 时连本地 HTML 导航也会报内部错误，已单独复现。因此 Chromium 使用原生离线模式，WebKit 阻断全部 HTTP(S) 请求；后者不能表述为系统断网测试。首次扩展测试还发现测试导航辅助器缓存了旧页面名，已改为实际应用导航并等待实际视图；未为此修改产品。中间失败与最终结果分别保留。

原有 WebKit 本地音频和 Linux WebKit 场景恢复的环境限制见 [扉页阶段记录](验证记录-4.16.3.md)。本次不宣称这些限制已经修复。
